Advantages
Start Here is a genuine full mode — first-timers get a clean, uncluttered welcome screen, not a modal layered over a confusing UI
Preview mode maximises 3D viewport — perfect for client review sessions
Output mode replaces viewport with the drawing/compliance viewer — output gets as much space as the 3D view
Mode bar is one consistent top-level navigation concept — easiest mental model
Trade-offs
Edit → Preview context switch can feel jarring — sidebar width changes on mode toggle
Power users need an extra click (switch to Edit mode) before touching any field
Output mode hides the 3D view (mitigated by persistent thumbnail) — a power user reviewing compliance while tweaking geometry must mode-switch
Best for: mixed-user audiences — first-timers get Start Here, reviewers get Preview, power users use Edit. Highest design payoff; moderate implementation complexity.
